Questions

Before you run a report.

Do I need SOPBot to use WorkflowIQ?

No - WorkflowIQ can analyze any documented process, not just ones generated by SOPBot. You'll need the text or a doc link for each SOP.

How do the tiers work?

Pick the tier that covers how many SOPs you want analyzed - up to 5, 6-15, or 16-30. Larger tiers also surface shared bottlenecks and automation opportunities that span multiple processes.

What if our process changes?

Run a new report on the updated SOP any time - pick whichever tier matches how many processes you're covering.

How is a report delivered?

As a PDF, ready to share with whoever owns the automation decision.

Is this a subscription?

No - pay per report, run one whenever you want a fresh read on where to automate next.
